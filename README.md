# PhiSci 2027 workshop website

Static website for the proposed ICLR 2027 workshop, **Physics-Inspired AI for Scientific Discovery: From Molecules to Materials**.

## Local preview

Open `index.html` directly in a browser, or serve this directory with any static web server.

## GitHub Pages

This repository is designed to publish from the root of the `main` branch with no build step.

1. Name the repository `phisci27.github.io` for the account-level Pages URL.
2. In **Settings > Pages**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder.

Workshop dates, speaker names, organizers, and submission information are intentionally marked as forthcoming until confirmed.
